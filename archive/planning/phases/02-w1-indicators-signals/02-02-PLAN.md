<objective>
Build the W1 indicator orchestrator and prove the full W1 indicator/signal/breadth chain end-to-end against a real PostgreSQL database.

`W1IndicatorService` is a thin orchestrator that sequences the four steps in the strict order required by the dependency chain: SuperTrend W1 -> RSI W1 -> signal detection -> W1 market breadth. All four underlying services are already timeframe-parameterized (Plan 01 added `computeForTimeframe` to the last one). This service gives Phase 3 a single clean call site to wire into `MarketPipelineService.runDaily()`.

`W1IndicatorPipelineIntegrationTest` is the Wave 0 test gap from RESEARCH.md — a single integration test class. Five test methods cover INDC-01, INDC-02, INDC-03, SGNL-01, SGNL-02 by exercising the individual services directly; a sixth method exercises the `W1IndicatorService` orchestrator end-to-end, proving its strict step ordering and completeness. All run against a Testcontainers Postgres instance.

Purpose: Satisfy all five Phase 2 requirements with verifiable, automated integration coverage and produce the orchestrator Phase 3 depends on — with the orchestrator itself directly validated.
Output: `W1IndicatorService.java` (orchestrator) and `W1IndicatorPipelineIntegrationTest.java` (6 passing integration tests).
</objective>
