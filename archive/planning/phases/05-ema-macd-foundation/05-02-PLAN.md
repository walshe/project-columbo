<objective>
Build the persistence and orchestration layer for EMA and MACD. This plan:

1. **EmaIndicator entity + EmaRepository** — JPA mapping for `indicator_ema`. Repository queries include `period` as a dimension because the same table stores 13-period (D1) and 26-period (W1) rows.

2. **EmaComputationService** — mirrors `RsiComputationService` exactly. Full-recalc from all finalized candles + upsert (insert/update/skip). Parameterised by period.

3. **MacdIndicator entity + MacdRepository** — JPA mapping for `indicator_macd`. MACD parameters (12-26-9) are hardcoded; no period column needed.

4. **MacdComputationService** — same upsert pattern as EmaComputationService.

5. **Pipeline wiring** — `MarketPipelineService` PHASE 2 gains two new lines (EMA 13 D1, MACD D1). `W1IndicatorService` gains one new phase (EMA 26 W1). MACD is NOT added to W1 (only W1 EMA slope is needed for the Impulse System's Screen 1 filter).

This plan is blocked on 05-01 (EmaCalculator.EmaResult and MacdCalculator.MacdResult must exist before services can be written).
</objective>
